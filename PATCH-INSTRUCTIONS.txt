LitRadar v0.7.0 → v0.7.1 patch

1. Make a backup of the LitRadar folder and data/litradar.sqlite3.
2. Extract this ZIP into the ROOT of the existing v0.7.0 folder and allow source files to be replaced.
3. Do not replace/delete your .env, local SQLite database, .venv, data/offline, data/source_cache, data/oa_cache, logs, or reports. None of those local data folders is bundled in this patch.
4. Run run_litradar.bat once. setup_litradar.bat installs requirements.txt, requirements-ui.txt, requirements-dev.txt, and requirements-llm.txt, then runs cli.py init.
5. Use run_cli.bat for a persistent activated CLI shell. Use run_telegram_bot.bat and keep it open for interactive Telegram commands/buttons. Scheduled Task Scheduler digest sending does not require the listener to be running.
6. For bot commands, ensure LITRADAR_TELEGRAM_BOT_TOKEN and LITRADAR_TELEGRAM_CHAT_ID are set in .env. Only one telegram-run process may poll a given bot token.

The patch is intended for v0.7.0. For any older release, use the corresponding full archive/upgrade path.
