LitRadar v0.6.0 -> v0.7.0 patch

1. Back up your LitRadar folder and data/litradar.sqlite3.
2. Extract all files in this archive into the root of the existing LitRadar v0.6.0 folder, merging folders and replacing files when prompted.
3. Keep your existing data/litradar.sqlite3, data/offline/, .env, .venv/, data/source_cache/, and data/oa_cache/.
4. Run run_litradar.bat once to confirm the environment/dependencies.
5. Run: python cli.py init
6. Run: python -m pytest -q
7. Edit digest_config.json before enabling a schedule.
8. For Windows scheduling: ensure .venv exists, then use install_schedule.bat. For Telegram, configure the optional bot token/chat ID in .env first.

Manual ZIP patch, not a Git patch. Contains new and changed project files only; no private DB or local configuration.
