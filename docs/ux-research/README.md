## Рекомендація

Напрям **Quiet Research / Спокійне читання**: нейтральні поверхні, виразна типографіка, помірний зелено-бірюзовий акцент, світла й темна теми, бібліотека як головне робоче місце. Зберегти всі п'ять розділів, API, статуси, provenance, історію, імпорт, фільтри та експорти. Граф підтримує читання й перевірку джерел; відсоток релевантності не виглядає як оцінка наукової якості.

Найперший інкремент — токени, типографіка та адаптивна оболонка. Наступний — бібліотека й читабельна панель публікації. Нові backend-можливості не є передумовою редизайну.

## Що підтверджено в початковій дослідницькій сесії

- Поведінку й межі функцій перевірено за `web/index.html`, `web/static/{app.js,styles.css,locales.js,graph-tools.js}`, `workspace_web.py`, чинними тестами та трьома репозиторними скриншотами.
- Розміри шрифтів і breakpoint-и — значення з CSS, не результати замірів очима учасників дослідження.
- Контраст рекомендованих пар кольорів обчислено за формулою відносної яскравості WCAG. Це перевірка палітри, не сертифікація всього UI.
- HTML-концепт пройшов перевірку синтаксису JavaScript, унікальності static IDs, локальних посилань і 12 DOM smoke checks у jsdom: 12 passed, 0 failed. Перевірені навігація, theme/density, пошук/статус, вибір роботи, чернетка між розділами, демо-save, provenance, keyboard tabs і graph selection. jsdom не перевіряє layout, рендеринг чи реальну доступність у браузері.
- Офіційні сайти конкурентів і W3C не відкрилися через мережеву політику: `Tunnel connection failed: 403 Forbidden`. Конкурентний блок — попередній аналіз відомих продуктових підходів, а не аудит актуальних залогінених версій. Поточні ціни, тарифи й ринкові частки не заявляються.
- Chromium із ввімкненим sandbox не запустився через конфігурацію SUID helper. Нові browser screenshots, перевірки reflow та usability-сесії не виконані; sandbox не вимикався. HTML-концепт потребує візуального приймання у звичайному браузері.

У початковій сесії для актуалізації конкурентного блоку було збережено чернетку вузького списку офіційних доменів у налаштуваннях cloud environment. Збереження чернетки саме по собі не застосовує мережевий доступ. Після застосування — виконати протокол із `sources.md`, оновити висновки й лише тоді називати конкурентний аудит завершеним.
