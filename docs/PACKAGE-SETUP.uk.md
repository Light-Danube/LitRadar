# Встановлення LitBeacon з готового wheel

Завантажте обидва файли — `litradar-1.0.0-py3-none-any.whl` і `SETUP.txt` — зі [сторінки релізу v1.0.0](https://github.com/Light-Danube/LitRadar/releases/tag/v1.0.0) та збережіть їх **в одній новій папці з правом запису**. Якщо натомість ви скористалися на GitHub командою **Code → Download ZIP** і бачите `cli.py`, `pyproject.toml` та `.bat`, відкрийте [інструкцію для Windows із вихідного ZIP](WINDOWS-SOURCE-ZIP.uk.md). Саме опублікований wheel пройшов перевірку встановлення в Linux; обмеження наведено в [контрольному списку релізу](archive/release-1.0/RELEASE-CHECKLIST-1.0.md).

Потрібні Python **3.11 або новіший** (рекомендовано 3.12) та інтернет для встановлення залежностей через pip. Для готового wheel не потрібні Git, Node, Docker, моделі, API-ключі чи вихідний код. Наведені команди задають `LITBEACON_HOME` як нову папку `user-data` для окремого пробного встановлення, щоб не відкривати наявну бібліотеку LitBeacon. Збережіть цю папку, якщо захочете залишити пробні дані.

## Windows 10/11 — PowerShell

1. За потреби встановіть **Python 3.12.x** із [python.org](https://www.python.org/downloads/windows/); виберіть 3.12, навіть якщо сайт пропонує новішу версію. Python 3.12.7 підходить. Перевірте `py -3.12 --version`. Збережіть обидва файли релізу в нову папку з правом запису, наприклад `Documents\LitBeacon-1.0.0-test`, і відкрийте PowerShell **у цій папці**. Переконайтеся, що тут є `SETUP.txt` і файл wheel.
2. Виконайте команди; активувати скрипти PowerShell не потрібно:

   ```powershell
   py -3.12 -m venv .venv
   $env:LITBEACON_HOME = (Join-Path (Get-Location) 'user-data')
   .\.venv\Scripts\python.exe -m pip install --no-cache-dir ".\litradar-1.0.0-py3-none-any.whl[web]"
   .\.venv\Scripts\python.exe -m pip check
   .\.venv\Scripts\python.exe -m cli --version
   .\.venv\Scripts\python.exe -m cli init
   .\.venv\Scripts\python.exe -m cli web
   ```

3. Відкрийте <http://127.0.0.1:8765> і переконайтеся, що на сторінці показано `v1.0.0`. Зупиніть сервер клавішами Ctrl+C. Для повторного запуску в тому самому вікні PowerShell повторіть останню команду; у новому вікні спочатку знову задайте `LITBEACON_HOME`. Якщо порт зайнято, запустіть `-m cli web --port 8787` і відкрийте відповідну адресу. У wheel немає `run_litbeacon_web.bat`: файли запуску `.bat` належать до вихідного коду.

Якщо `py -3.12` не працює, перевірте встановлення засобу запуску разом із Python командою `py --list`. Команда pip для Windows вимикає кеш pip. Якщо помилка доступу залишається, скористайтеся новою папкою з правом запису та повідомте команду, версію Python і перший безпечний рядок помилки, не надсилаючи приватні шляхи, бібліотеку, `.env`, токени чи журнали. [Стан перевірок на різних платформах](archive/release-1.0/RELEASE-CHECKLIST-1.0.md).

## macOS — Термінал

1. За потреби встановіть **Python 3.12.x** із [python.org](https://www.python.org/downloads/macos/) і перевірте `python3 --version` (потрібна версія 3.11+). Системний Python може бути застарілим. Збережіть обидва файли релізу в нову папку з правом запису та відкрийте в ній Термінал.
2. Виконайте:

   ```sh
   python3 -m venv .venv
   export LITBEACON_HOME="$PWD/user-data"
   ./.venv/bin/python -m pip install './litradar-1.0.0-py3-none-any.whl[web]'
   ./.venv/bin/python -m pip check
   ./.venv/bin/python -m cli --version
   ./.venv/bin/python -m cli init
   ./.venv/bin/python -m cli web
   ```

3. Відкрийте <http://127.0.0.1:8765>. Зупиніть сервер клавішами Ctrl+C та запустіть його знову тією самою командою в тому самому Терміналі. У новому вікні Термінала знову задайте `LITBEACON_HOME`. Сам wheel написаний на Python, але його залежностям потрібні сумісні з вашими Python і процесором пакети для macOS. **Встановлення та роботу браузера безпосередньо в macOS для цієї версії ще не перевірено.**

## Linux — термінал

1. Перевірте `python3 --version` (3.11+). Якщо `venv` повідомляє про відсутність `ensurepip`, встановіть пакет віртуальних середовищ Python для свого дистрибутива (наприклад, `python3-venv` у Debian/Ubuntu). Збережіть обидва файли релізу в нову папку з правом запису й відкрийте в ній термінал.
2. Виконайте:

   ```sh
   python3 -m venv .venv
   export LITBEACON_HOME="$PWD/user-data"
   ./.venv/bin/python -m pip install './litradar-1.0.0-py3-none-any.whl[web]'
   ./.venv/bin/python -m pip check
   ./.venv/bin/python -m cli --version
   ./.venv/bin/python -m cli init
   ./.venv/bin/python -m cli web
   ```

3. Відкрийте <http://127.0.0.1:8765> і зупиніть сервер клавішами Ctrl+C. У новому вікні термінала перед повторним запуском знову задайте `LITBEACON_HOME`. Перевірка встановленого wheel у Linux охоплює вебресурси пакета, але безголовий тест не доводить правильність вигляду у справжньому браузері чи сумісність залежностей з усіма дистрибутивами.

## Дані, необов’язкові компоненти та оновлення

Браузерний сервер слухає лише localhost і не має входу за паролем; не відкривайте його для локальної мережі чи інтернету. Встановлення залежностей і явно запущений пошук у наукових джерелах використовують мережу; робота зі збереженою бібліотекою відбувається локально. Для першого запуску провайдер чи модель не потрібні.

Поза описаною ізольованою пробою дані встановленого пакета за замовчуванням зберігаються в `%LOCALAPPDATA%\LitBeacon` у Windows, `~/Library/Application Support/LitBeacon` у macOS та `$XDG_DATA_HOME/LitBeacon` у Linux (зазвичай `~/.local/share/LitBeacon`). `LITBEACON_HOME` треба задавати перед кожним новим процесом. Папку пробних даних `user-data` можна видалити лише тоді, коли ці дані більше не потрібні. Встановлений wheel не копіює стару бібліотеку з вихідного коду. Див. [розташування даних wheel](USER-GUIDE.md#wheel-installation) і [резервне копіювання та відновлення](USER-GUIDE.md#consistent-local-backup-and-restore).

Для необов’язкового TUI та імпорту файлів замініть `[web]` у команді pip на `[web,ui,annotations]`, а потім запустіть `-m cli ui` тим самим інтерпретатором із `.venv`. LLM, Telegram і локальні ембеддинги потребують окремого свідомого налаштування. Встановлення завдань Windows Task Scheduler і файли запуску `.bat` вимагають вихідного коду; користувачі wheel можуть налаштувати власний планувальник. [Посібник користувача](USER-GUIDE.md) · [використання мережі](NETWORK-USE.md) · [журнали](LOGGING.md).

Віртуальне середовище прив’язане до тієї версії Python, з якою його створено: встановлення Python 3.12 не перетворює старе `.venv`. Для вихідного коду засоби запуску LitBeacon зберігають невідповідне або пошкоджене середовище як `.venv-before-python312` і створюють нове `.venv`. Для wheel збережіть нові файли релізу в іншу папку та створіть у ній нове `.venv`. Зберігайте старі середовища, доки не перевірите нове встановлення.

Щоб оновитися з v0.8.0, **зупиніть усі процеси LitBeacon і спочатку зробіть резервну копію**. Якщо команда доступна, у старому середовищі виконайте `-m cli library-backup NEW_BACKUP_DIRECTORY`; явно додайте файли Research/offline лише після зупинки процесів запису. Окремо збережіть профілі, налаштування дайджесту та облікові дані. Якщо в старій версії такої команди немає, встановіть новий wheel в **окреме `.venv`** і виконайте `-m cli --db OLD_DATABASE library-backup NEW_BACKUP_DIRECTORY` *до* `init` чи `web`; стара база відкриється лише для читання. Тримайте резервну копію поза папкою встановлення. Потім встановіть нову версію в окрему папку та використайте те саме місце для даних користувача, якщо хочете оновити наявну бібліотеку. `init` виконує поступові міграції; бібліотеки з вихідного коду автоматично не переносяться. Ніколи не видаляйте стару папку даних для виправлення встановлення. [Докладніше про відновлення](USER-GUIDE.md#consistent-local-backup-and-restore).

У вихідному коді немає опублікованого wheel. [Стан перевірки релізу](archive/release-1.0/RELEASE-CHECKLIST-1.0.md).
