# LitBeacon Wiki

LitBeacon is a local research workspace for papers, notes, citation maps and evidence. Your library stays in SQLite on your computer. The web interface is for localhost use; provider searches and installation dependencies need network access.

Start with the [LitBeacon overview](https://github.com/Light-Danube/LitRadar#readme). Install from the [v1.0.0 release](https://github.com/Light-Danube/LitRadar/releases/tag/v1.0.0) using the [Windows, macOS or Linux wheel guide](https://github.com/Light-Danube/LitRadar/blob/main/docs/PACKAGE-SETUP.md). Windows users can also follow the [source-ZIP guide](https://github.com/Light-Danube/LitRadar/blob/main/docs/WINDOWS-SOURCE-ZIP.md).

For everyday use, see the [user guide](https://github.com/Light-Danube/LitRadar/blob/main/docs/USER-GUIDE.md), including backup and restore. [Українські інструкції для wheel](https://github.com/Light-Danube/LitRadar/blob/main/docs/PACKAGE-SETUP.uk.md) and [Windows ZIP](https://github.com/Light-Danube/LitRadar/blob/main/docs/WINDOWS-SOURCE-ZIP.uk.md) are available. The [documentation index](https://github.com/Light-Danube/LitRadar/blob/main/docs/README.md) links to networking, logging, Telegram help and optional features.

The [release checklist](https://github.com/Light-Danube/LitRadar/blob/main/docs/LOCAL-1.0-RELEASE-CHECKLIST.md) records which platform checks were executed and which remain unverified. Please report reproducible problems through [Issues](https://github.com/Light-Danube/LitRadar/issues) without attaching personal libraries, credentials or private logs.
