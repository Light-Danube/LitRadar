# Повторна перевірка конкурентів — 2026-10-13

Офіційні сторінки нижче прочитані через HTTPS (усі HTTP 200, без перенаправлення). Це аналіз HTML документації та публічних сторінок: без акаунтів, оплат, особистих даних, запуску продуктових сценаріїв чи вимірювання usability. Попередні 403 у початковому дослідженні були реальним обмеженням тієї сесії; тепер доступ до цих сторінок є. Рівень доказів **P: прочитане публічне джерело**, а не hands-on.

## Корекція початкового драфту

Публічні джерела підтримують розподіл на бібліографічні менеджери, засоби читання, графове discovery та evidence workflows. Вони **не доводять**, що конкретні кольори, три колонки або вкладки покращать роботу користувачів LitBeacon. Тому Phase 1 обмежена токенами, оболонкою, типографікою, темами й фокусом; нове компонування detail/provenance лишається гіпотезою для Phase 2.

Візуальний напрям: нейтральна поверхня, сильні назви публікацій, стриманий зелено-бірюзовий акцент, контрастні службові тексти, послідовні контроли. Не копіюємо бренд конкурента. Замість довільного рейтингу продуктів наступне дослідження має порівняти час і помилки в завданнях «знайти → прочитати → занотувати → перевірити джерело → повернутися».

Ціни, ринкова частка, кількість клієнтів, достовірність рекламних відгуків та порівняльна ефективність не перевірялися. Повний протокол hands-on із [sources.md](sources.md) залишається відкритим.
