# LitBeacon 1.0

LitBeacon 1.0 is a local research workspace with a browser interface, CLI, and optional Textual TUI and Telegram workflows. Libraries, notes, evidence and research history stay in local SQLite. Since 0.8.0, this release adds venue search and evidence worksheets, consistent library backup and new-destination restore, annotation and citation-map improvements, and installation fixes. Optional local semantic exploration remains off by default.

Download **both** `litradar-1.0.0-py3-none-any.whl` and `SETUP.txt` from this release into the same writable folder. Use Python 3.12 and follow the [Windows, macOS or Linux package guide](https://github.com/Light-Danube/LitRadar/blob/main/docs/PACKAGE-SETUP.md); [Windows source-ZIP instructions](https://github.com/Light-Danube/LitRadar/blob/main/docs/WINDOWS-SOURCE-ZIP.md) are a separate path. Dependencies require an internet connection during installation. The browser listens on localhost and is not intended for public or LAN hosting. Back up your library before upgrading; a wheel install does not move data from an older source checkout automatically.
